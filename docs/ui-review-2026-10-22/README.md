# UI review, 22 October 2026

The before and after directories contain selected synthetic ImageRenderer layouts. They show spacing and text hierarchy. Their opaque export background and AppKit control substitutes do not establish native Liquid Glass appearance or live meeting behavior.

The native/settings-dark.jpg file is a JPEG captured from the separate native preview window after correcting labels that clipped in the native form. It contains synthetic preferences. It is not an ImageRenderer export. No actual meeting, participant, transcript, credential or user file is included.

The cleanup layouts now use the real AudioCleanupView with debug-only synthetic rows. Preview deletion is disabled before any file operation. Native table chrome is substituted only in image exports.

The source and acceptance limits are in [Liquid Glass UI](../liquid-glass-ui.md) and [Apple design adoption audit](../macos-design-audit.md). The complete private matrix contains 48 layouts plus palette checks. Only these reviewed synthetic images are published.
